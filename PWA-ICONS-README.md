 # Генерация иконок для PWA (Android/Xiaomi)

⚠️ **ВАЖНО**: Для корректной работы приложения на Android/Xiaomi **обязательно** нужны PNG иконки размеров 192x192 и 512x512 пикселей. Без них приложение будет открываться как сайт в браузере, а не как полноценное приложение.

## Быстрый способ (онлайн)

1. Перейди на один из сервисов:
   - https://favicon.io/favicon-converter/
   - https://quickfavs.com/
   - https://changecrab.com/tools/favicon-generator

2. Загрузи свой `favicon.ico` или логотип

3. Скачай сгенерированные иконки:
   - `icon-192.png` (192x192)
   - `icon-512.png` (512x512)

4. Помести их в папку `public/`:
   ```
   public/icon-192.png
   public/icon-512.png
   ```

## Альтернативный способ (ImageMagick)

Если установлен ImageMagick:

```bash
# Из favicon.ico
convert public/favicon.ico -resize 192x192 public/icon-192.png
convert public/favicon.ico -resize 512x512 public/icon-512.png
```

## Проверка

После добавления иконок:
1. Очисти кеш браузера на устройстве (Chrome → Настройки → Конфиденциальность → Очистить данные просмотра)
2. Удали приложение с главного экрана (если было установлено ранее)
3. Открой сайт в Chrome на Android/Xiaomi
4. В меню (три точки) выбери "Добавить на главный экран" или "Установить приложение"
5. Приложение должно установиться как полноценное приложение:
   - ✅ Без адресной строки
   - ✅ Без панели навигации браузера
   - ✅ С иконкой на главном экране
   - ✅ Открывается как отдельное приложение

## Если приложение всё ещё открывается как сайт

1. Проверь, что файлы `icon-192.png` и `icon-512.png` существуют в папке `public/`
2. Проверь, что они доступны по URL: `https://твой-домен.ru/icon-192.png`
3. Очисти кеш сервера (если используется CDN/кеширование)
4. Перезагрузи устройство
5. Попробуй установить через Chrome DevTools (F12 → Application → Manifest → Install)

## Важно для Xiaomi

- Убедись, что `display: "standalone"` в `manifest.json` (уже настроено)
- Иконки должны быть в формате PNG
- Рекомендуется использовать maskable иконки (с padding для адаптации под разные формы)
